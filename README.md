# 🏠 House Price Prediction using Machine Learning

## 📌 Overview
This project builds a Machine Learning model to predict house prices based on different features such as location, size, and other relevant factors. It demonstrates the complete ML pipeline from data preprocessing to model evaluation.

---

## ⚙️ Technologies & Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset
- The dataset is in CSV format.
- Contains housing features and corresponding prices.
- Used for training and testing the regression model.

---

## 🚀 Workflow
1. **Data Loading**
2. **Data Preprocessing**
   - Handling missing values  
   - Encoding categorical variables  
   - Feature scaling  
3. **Exploratory Data Analysis (EDA)**
   - Visualization using Seaborn & Matplotlib  
4. **Feature Engineering**
5. **Model Training**
   - Train-test split  
   - Applying regression model  
6. **Model Evaluation**
   - MAE, MSE, R² Score  

---

## 📊 Model Used
- Random Forest Regressor (main model)
- Other regression techniques can also be applied

---

## 🧪 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
